# Course hub kit (concept)

Combines Google Classroom's stream/banner/tabs with Moodle's topic sections and activity completion. **No product spec or screens exist for this surface** (the infinite-canvas spec lists "no Classroom tray", "no student join"); this kit exists to show how the system handles the Classroom/Moodle side. Content is invented sample data; treat the layout as a proposal, not a requirement.

Flow: switch Tablón / Trabajo de clase; open/close unit sections; click a completion circle to cycle none → todo → done.
