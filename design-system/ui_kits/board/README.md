# Lesson board kit

Recreates screens C0 (board), C1 (Overlay notice), C3 (PDF viewer) and the clear-board confirm from `.tlk/features/2026-11-09-infinite-canvas/ux-design.md`. Cosmetic only: no real pan/zoom/ink; the PDF page is a labelled placeholder.

Flow: dismiss notice with "Entendido" → switch tools → tap the OverlayChip (? → ON → OFF) → "Abrir libro" opens the viewer → prev/next → back → trash opens the confirm dialog → save shows a toast.
